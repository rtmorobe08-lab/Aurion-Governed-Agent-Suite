# AURION AGENT GOVERNANCE CHARTER
Version 1.0 · 2 November 2026 · Status: DRAFT FOR DIRECTOR RATIFICATION
Aurion Enterprises (Pty) Ltd · Reg 2026/466313/07

The normative rules live in `governance/governance_parameters.json`. This charter is the plain-language
version of the same rules, written so a client, auditor or funder can read it without a technician beside them.
Where the two disagree, the parameters file governs and this charter is corrected.

## 1. The commitment
Every Aurion agent runs under a passport, inside limits, on a log, with a human above it.
An agent that cannot prove it is permitted to act does not act. That is the whole doctrine; the rest is detail.

## 2. Five tiers of action
| Class | Tier | Meaning |
|---|---|---|
| Read only | T0 | Reads, computes, drafts nothing external |
| Draft internal | T0 | Produces drafts that never leave the organisation |
| Notify then act | T1 | Acts within caps, reversible, tells the owner immediately |
| Approve then act | T2 | Prepares the action and waits for a named human |
| Human only | T3 | Never executed by an agent |

T3 is not a preference, it is a wall: payments, statutory filings, tender submissions, contract signatures,
employee bank changes, disciplinary matters, credit decisions and data-subject responses are never automated.

## 3. Disclosure
Every external interaction opens by naming what it is: "you are speaking with the office assistant."
Deception is prohibited by design, not by policy. Disclosure is recorded in the log for each interaction.

## 4. The kill switch
Any authorised human stops any agent within three seconds. Activation is logged. Restarting requires
re-authorisation. It is tested monthly, because an untested kill switch is a story, not a control.

## 5. Money
Agents never move money. They prepare, categorise, flag and draft. Caps apply by hour, day, month, and
breaching a cap blocks and escalates rather than proceeds.

## 6. Personal information
POPIA is the floor. Special personal information and children's data are prohibited by default. Cross-border
transfers are off by default. Data is minimised to the stated purpose, kept under a written retention rule
(five years for logs, ninety days for call recordings), and deleted on request within thirty days.

## 7. Evidence
Every action writes an attributed, append-only register record: which agent, which passport version, what
action class, what target, what data it touched, on what basis, who approved it, and whether it can be
reversed. The register is the system of record, and it is the artefact a bank, board or auditor is shown.

## 8. Change control
Any change to scope, data classes, tools, caps or gates requires a passport version bump and re-approval.
Models and prompts are pinned and recorded. Silent model swaps are prohibited.

## 9. Incidents
Acknowledge within 24 hours, report within 72. Severity determines escalation. Every incident enters the
register. The Watchtower agent feeds Active AI Defence; when a guardrail trips, a human is already being told.

## 10. People
Every agent has a named owner who attests monthly. Governance audits run quarterly, external audit annually.
The Information Officer is named. Escalation reaches a human on WhatsApp, not a ticket queue.
